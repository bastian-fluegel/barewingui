# BareWinGUI

BareWinGUI ist ein Framework für native Windows-GUIs in Python.

Es setzt auf die Win32-API über `ctypes` — ohne externe pip-Abhängigkeiten, nur mit der Python-Standardbibliothek und nativen Windows-DLLs.

> **Status:** Das Projekt befindet sich aktuell noch in den ersten Schritten der Entwicklung. Die öffentliche API ist unvollständig und kann sich jederzeit ändern.

## Ziele

- Zero-Dependency (kein pip-Stack, nur `ctypes` + Win32)
- Native Windows-Controls statt Web- oder Cross-Platform-Rendering
- Deterministische, lineare Event-Loops
- Python 3.11+
