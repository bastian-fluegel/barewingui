BareWinGUI Referenz BareWinGUI Reference

Deterministisches Win32-GUI-Framework für Python 3.11+. Direkte Kernel- und User-DLL-Anbindung via ctypes ohne Web-Engines, MSVC-Laufzeiten oder Drittpakete. Deterministic Win32 GUI framework for Python 3.11+. Direct kernel and subsystem binding via ctypes without web engines, MSVC runtimes, or third-party packages.

Architektur-Vorgaben:
  • Supply-Chain-Sicherheit: dependencies = []. Keine fremden CVEs in administrativen, forensischen oder KRITIS-Umgebungen.
  • Deterministischer Footprint: Kaltstart unter 15 ms, Leerlauf < 15 MB RAM.
  • Native Windows 10/11 Ästhetik: Typografische Anbindung an Segoe UI und Aktivierung der Common Controls v6.
 Architectural Directives:
  • Supply Chain Hardening: dependencies = []. Zero foreign CVE exposure for administrative, forensic, or high-assurance networks.
  • Deterministic Footprint: Cold boot < 15 ms, idle memory < 15 MB RAM.
  • Native Windows 10/11 Rendering: Typographic anchoring to Segoe UI and Comctl32 v6 visual styles.

VBox / HBox Layout Engine VBox / HBox Layout Engine

Dynamische Anordnung ohne starre Pixel-Koordinaten. Passt Steuerelemente automatisch an Größenänderungen an. Dynamic component positioning eliminating rigid coordinate offsets. Automatically scales controls during resize events. 

from barewingui import VBox, HBox, Button, TextInput

root = VBox(padding=12, spacing=8)
root.add(TextInput(win), stretch=1)

bar = HBox(spacing=8, padding=0, fixed_size=32)
bar.add_stretch()
bar.add(Button(win, text="Start", size=(100, 32)))
root.add(bar)

root.attach(win)
