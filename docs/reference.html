1. Sicherheitsdoktrin & Leitprinzipien 1. Security Doctrine & Guiding Principles

BareWinGUI ist ein minimalistisches Win32-GUI-Framework für Python 3.11+. Es bindet direkt über ctypes an die Betriebssystem-DLLs von Windows an — vollständig ohne externe Python-Pakete, C++-Compiler, WebView2 oder Node.js. BareWinGUI is a minimalist Win32 GUI framework engineered for Python 3.11+. Binding directly to core Windows DLLs via ctypes, it completely eliminates third-party packages, C++ compiler toolchains, WebView2, and Node.js runtimes.

Architektur-Vorgaben:
  • Supply-Chain-Sicherheit: dependencies = []. Null Drittanbieter-Risiken für OT/SCADA, Incident-Response und KRITIS-Systeme.
  • Deterministischer Footprint: Kaltstart unter 15 ms, Basisspeicher < 15 MB RAM.
  • Native Windows 10/11 Integration: Automatische Segoe UI-Schriftzuweisung und Common Controls v6 Theming.
 Architectural Directives:
  • Supply Chain Hardening: dependencies = []. Zero third-party CVE exposure for OT/SCADA, IR toolsets, and critical infrastructures.
  • Deterministic Footprint: Cold boot < 15 ms, idle memory consumption < 15 MB RAM.
  • Native Windows 10/11 Rendering: Automatic Segoe UI font propagation and comctl32 v6 visual styling.

3. DPI & Application Lifecycle (barewingui.core) 3. DPI & Application Lifecycle (barewingui.core)

Verwaltet Prozess-Initialisierung, Per-Monitor DPI Awareness v2 und die synchrone Message-Pump. Manages process bootstrapping, Per-Monitor DPI Awareness v2, and the synchronous message dispatch loop.

Application.initialize()

Initialisiert SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2) und lädt Comctl32 v6 einmalig pro Prozess. Applies SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2) and loads Comctl32 v6 once per process.

Application.run(main_window=None) -> int

Startet die native GetMessageW/DispatchMessageW-Schleife. Blockiert, bis alle Fenster geschlossen sind oder Application.quit() aufgerufen wird. Enters the native GetMessageW/DispatchMessageW pump. Blocks until all top-level windows terminate or Application.quit() is invoked.

5. VBox / HBox Layout Engine (barewingui.layout) 5. VBox / HBox Layout Engine (barewingui.layout)

Schlankes Box-Sizer-System für dynamische Steuerelement-Anordnung ohne statische Pixel-Offsets. Lightweight box-sizer layout engine providing responsive alignment without absolute coordinate binding. 

from barewingui import VBox, HBox, Button, TextInput

root = VBox(padding=12, spacing=8)
root.add(TextInput(win), stretch=1)  # Expandiert flexibel

bar = HBox(spacing=8, padding=0, fixed_size=32)
bar.add_stretch()                    # Drückt Elemente nach rechts
bar.add(Button(win, text="Start", size=(100, 32)))
root.add(bar)

root.attach(win)                     # Verbindet Layout mit WM_SIZE des Fensters

6. Steuerelemente (barewingui.controls) 6. Control Components (barewingui.controls)

Button, CheckBox, RadioButton

Basieren auf der Win32-Fensterklasse BUTTON. Native controls powered by the Win32 BUTTON window class.

  • Button(parent, text="Click", on_click=func, default=False)
  • CheckBox(parent, text="Logging", checked=True, on_click=func)
  • RadioButton(parent, text="Mode", checked=False, group_start=False)

Label & TextInput

Beschriftungen und Textfelder mit transparenter Hintergrundbehandlung via WM_CTLCOLORSTATIC. Static text and edit inputs with transparent background handling via WM_CTLCOLORSTATIC.

  • Label(parent, text="Host:", align="left"|"center"|"right")
  • TextInput(parent, text="", multiline=False, password=False, readonly=False, on_change=func)

ComboBox & ListBox

Auswahlelemente mit automatischer Dropdown-Höhenkorrektur. Selection lists resolving native Win32 dropdown height collapse issues.

  • ComboBox(parent, items=["A", "B"], selected_index=0, on_change=func)
  • ListBox(parent, items=["Log 1", "Log 2"], on_change=func, on_double_click=func)
